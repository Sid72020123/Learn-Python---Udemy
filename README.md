# Learn-Python-Udemy

My personal collection of **code, solutions, and projects** completed as part of Udemy's [100 Days of Code™: The Complete Python Pro Bootcamp](https://www.udemy.com/course/100-days-of-code/).

## 📂 Repository Structure

Each course day or section is organized into a separate folder within the [`src/`](src/) directory, following the naming convention `Day <number>`, where `<number>` corresponds to the respective day or section of the course.

Depending on the section, its folder may contain a `project_<number>.py` file with the solution to a project or coding challenge assigned in the course. Some sections are entirely project-based and may follow a different structure.
